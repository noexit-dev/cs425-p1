## Experience

My experience with the project I will say was quite rough. I first started reading how the protocol worked and how to access and open up a socket. This was a struggle for me because it was difficult to find where to look to access the socket. I will say Geeks for Geeks had some great examples for how to access the server hostname with a struct. I first started with the small stuff I was able to successfully able to open a socket, get the address of the hostname passed in, and read the reply from the server successfully. Then I built off of that, making the complete "handshake" that is the SMTP protocol. It was a cool project, but reflecting on it I would have liked to have had maybe some more time in class to go over protocols more in depth.
